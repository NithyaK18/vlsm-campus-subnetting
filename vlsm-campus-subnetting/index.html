Zero-Waste Campus Subnetting

Each facility gets the smallest block that holds its hosts. Change the address block or the requirements and the whole plan recalculates.

Requirements

FacilityHosts

Hosts means usable device addresses. Each block also needs one network and one broadcast address.

How each size was chosen

Block size is the smallest power of two that holds the hosts plus the network and broadcast addresses. Placing the largest block first keeps every block aligned on its own boundary, so nothing is lost to gaps.
